PR Genie

A local runner that drives Cursor agents through build, then draft PR, then automated review and fix rounds — on your own machine.

npx -y prgenie@latest init
GitHub npm

Requires Node.js 22+, git, GitHub CLI (gh), and cursor-agent for real jobs.

How it works

Wire MCP stdio (prgenie-runner) or the optional HTTP dashboard, then start jobs. Merging the PR stays your call.

  1. Step 1

    Start a job

    Call start_job with a repo path, branch name, and prompt file (via MCP or the dashboard).

  2. Step 2

    Build

    The implementor agent works in a git worktree and lands commits on your feature branch.

  3. Step 3

    Draft PR

    The runner commits, pushes, and opens a draft GitHub pull request when the build stage succeeds.

  4. Step 4

    Review and fix

    Reviewer agents approve or request changes; fixer agents address findings. The loop runs for up to your configured review rounds (default 3, max 10). You promote or merge when ready.

Features

Linux, macOS, and Windows

Same npm runner on major desktop OSes; use PowerShell or terminal per the npm README for Windows setup.

Per-stage models

Pick models for build, review, and fix stages via stageModels or runner defaults in Setup.

Dashboard on your LAN

Optional prgenie serve UI on localhost; bind 0.0.0.0 to reach it from other devices on your network.

HTTP and MCP API

Stdio MCP (npx -y prgenie mcp) needs no token; HTTP MCP and the dashboard use a bearer token from prgenie init.

Queued jobs

Jobs queue with a configurable concurrency limit (maxActiveJobs, up to 8).

Your credentials

Runs locally with your own git remotes and gh auth — no hosted agent farm.

Quickstart

Install once per machine. Server id prgenie-runner keeps the runner separate from the Cursor plugin's prgenie steward MCP.

  1. Initialize data dir and token (for HTTP serve later) 
    npx -y prgenie init
  2. Check prerequisites 
    npx -y prgenie doctor
  3. Start the optional HTTP dashboard 
    npx -y prgenie serve

    Open http://127.0.0.1:9473/ and paste the token from runner.token. Wire MCP with npx -y prgenie config --client cursor when you are ready for stdio jobs.
